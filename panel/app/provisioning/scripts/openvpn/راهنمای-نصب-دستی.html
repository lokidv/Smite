📌 این پروژه چیست؟

این نصب‌کننده، معادلِ OpenVPN نسخهٔ WireGuard است: نصب خودکار OpenVPN + همهٔ پیش‌نیازها + یک پنل ادمین و API برای مدیریت کاربران با حجم (Data Limit)، تاریخ انقضای خودکار، فعال/غیرفعال‌سازی و دانلود فایل .ovpn.

هستهٔ VPN: OpenVPN (پایهٔ angristan)
پنل و API: Node.js روی پورت 4000
پورت OpenVPN: پیش‌فرض 1194/UDP
مسیر فایل‌ها: /home/ovpn

🧩 پیش‌نیازها

  • یک سرور Ubuntu یا Debian تازه (حتی بدون Node.js و OpenVPN).
  • دسترسی root (یا sudo).
  • دسترسی به اینترنت (برای دریافت apt / openvpn / Node.js).
توجه: همهٔ پیش‌نیازها (openvpn، easy-rsa، qrencode، jq، socat، iptables، Node.js 20) خودکار نصب می‌شوند؛ نیازی به نصب دستیِ آن‌ها نیست.

🚀 نصب با یک دستور

پوشهٔ پروژه (ovpn-installer) را روی سرور کپی کنید و با root اجرا کنید:

cd ovpn-installer
sudo ./install.sh

نصب کاملاً خودکار و بدون پرسش است. برای حالت تعاملی (پرسیدن سؤالات):

sudo OVPN_NONINTERACTIVE=0 ./install.sh
نمونهٔ سفارشی: پورت 443 روی TCP، حجم پیش‌فرض ۳۰ گیگ، و یک کاربر تستی: 
sudo OVPN_VPN_PORT=443 OVPN_PROTOCOL=tcp \
     OVPN_DEFAULT_LIMIT_GB=30 OVPN_TEST_CLIENT=alice ./install.sh

⚙️ تنظیمات نصب (متغیرهای محیطی)

هر کدام را می‌توانید قبل از ./install.sh ست کنید (اختیاری):

متغیرپیش‌فرضتوضیح
OVPN_PORT4000پورت پنل و API
OVPN_VPN_PORT1194پورت OpenVPN
OVPN_PROTOCOLudpudp یا tcp
OVPN_DNS1 / OVPN_DNS21.1.1.1 / 1.0.0.1DNS کلاینت‌ها
OVPN_ENDPOINTIP سرورآدرس Remote کلاینت (برای NAT)
OVPN_DEFAULT_LIMIT_GBنامحدودحجم پیش‌فرض کاربران جدید (گیگ)
OVPN_TEST_CLIENT—ساخت یک کاربر تستی بعد از نصب
OVPN_NONINTERACTIVE10 برای حالت تعاملی

🔑 اطلاعات دسترسی بعد از نصب

در پایانِ نصب، آدرس پنل، رمز ادمین و API Key چاپ و در فایل زیر ذخیره می‌شود:

cat /root/ovpn-install-info.txt

محتوای نمونه:

Server IP    : 1.2.3.4
OpenVPN      : udp 1.2.3.4:1194
Panel URL    : http://1.2.3.4:4000/p-XXXXXXXX/
Admin Pass   : <رمز ادمین>
API Key      : <کلید API>
مهم: رمز ادمین فقط یک‌بار در نصبِ اول نمایش داده می‌شود (بعد از آن فقط hash ذخیره می‌شود). اگر روی سروری که از قبل نصب بوده دوباره نصب کنید، این خانه خالی می‌ماند — در این حالت از بخش ریست رمز استفاده کنید.

🖥️ ورود به پنل ادمین

آدرس پنل به شکل زیر است (مسیرِ تصادفیِ امن دارد):

http://SERVER_IP:4000/<ADMIN_PATH>/
  • با رمز ادمین (از فایل info) وارد شوید.
  • در پنل می‌توانید کاربر بسازید، حجم و انقضا تعیین کنید، فعال/غیرفعال کنید و فایل .ovpn را دانلود کنید.
فایروال: مطمئن شوید پورت پنل (4000/TCP) و پورت OpenVPN (1194/UDP یا پورت انتخابیِ شما) در فایروال باز باشد.

🔌 مدیریت با API

همهٔ روت‌ها با هدر X-API-Key یا پارامتر ?apiKey= کار می‌کنند. مقدار KEY را از فایل info بردارید.

عملیاتروت
ساخت کاربر (خروجی=فایل ovpn.)/create?apiKey=KEY&name=alice&dataLimitGB=30&expiresInDays=60
اطلاعات کاربر/info?apiKey=KEY&name=alice
افزایش حجم و تمدید/update?apiKey=KEY&name=alice&addDataGB=10&extendDays=30
غیرفعال / فعال/disable?...&name=alice · /enable?...&name=alice
حذف کاربر/remove?apiKey=KEY&name=alice
لیست کاربران (با فیلتر)/list?apiKey=KEY&status=active&sort=usedBytes&order=desc

نمونهٔ ساخت کاربر و ذخیرهٔ فایل کانفیگ:

KEY="کلید-از-فایل-info"
curl -s "http://SERVER_IP:4000/create?apiKey=$KEY&name=alice&dataLimitGB=30&expiresInDays=60" -o alice.ovpn
نکته: پارامترهای حجم/انقضا چند نام را می‌پذیرند (مثل volume، data_limit_gb، volumeBytes).

⌨️ مدیریت با خط فرمان

systemctl status ovpn.service                 # وضعیت پنل
systemctl status openvpn-server@server        # وضعیت OpenVPN
journalctl -u ovpn.service -f                 # لاگ زندهٔ پنل

/home/ovpn/ovpn-manager.sh list               # لیست و وضعیت کاربران
/home/ovpn/ovpn-manager.sh enforce            # اعمال دستیِ محدودیت‌ها

لایهٔ Enforce هر ۳۰ ثانیه (پنل) و هر ۱ دقیقه (کرون پشتیبان) کاربرِ منقضی یا پُر-حجم را خودکار قطع می‌کند.

🔁 فراموشی / ریست رمز ادمین

اگر رمز را ندارید (مثلاً نصبِ مجدد بوده)، یک رمز جدید بسازید و جایگزین کنید:

cd /home/ovpn
sudo OVPN_CONFIG_DIR=/etc/ovpn node -e 'const c=require("./lib/config.js");const p=require("crypto").randomBytes(12).toString("base64url");c.rotateAdminPassword(p);console.log("رمز جدید ادمین:",p)'
sudo systemctl restart ovpn.service

رمزی که چاپ می‌شود، رمز جدیدِ ورود به پنل است (رمز قبلی باطل می‌شود).

🩺 عیب‌یابی و نکات

  • QR کد: کانفیگ OpenVPN حدود ۳ کیلوبایت است و از ظرفیت QR بزرگ‌تر است؛ پس همیشه از دانلود فایل .ovpn استفاده کنید.
  • تغییر DNS: تغییر DNS در پنل یک‌بار OpenVPN را ری‌استارت می‌کند و اتصال کلاینت‌های فعلی موقتاً قطع می‌شود.
  • کاربر وصل نمی‌شود: پورت OpenVPN را در فایروال/کلود بررسی کنید و مطمئن شوید openvpn-server@server فعال است.
  • اطلاعات دسترسی: همیشه در /root/ovpn-install-info.txt است.

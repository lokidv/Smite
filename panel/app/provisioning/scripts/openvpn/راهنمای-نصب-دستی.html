راهنمای گام‌به‌گام — نصب دستی

🔐 نصب OpenVPN روی سرور، قدم به قدم

فقط مرحله‌ها را از بالا به پایین دنبال کن. هر دستور یک دکمهٔ «کپی» دارد؛ کپی کن و در ترمینال سرور بزن.

🎯 در یک نگاه: کل کار ۵ مرحله است

  1. به سرور وصل شو (SSH)
  2. پوشهٔ نصب‌کننده را روی سرور کپی کن
  3. یک دستور نصب بزن و منتظر بمان
  4. رمز ادمین و آدرس پنل را بردار
  5. وارد پنل شو و کاربر بساز
1

به سرور وصل شو

💻 روی کامپیوترِ خودت

یک ترمینال باز کن و با SSH وارد سرور شو. به‌جای SERVER_IP آی‌پیِ سرورت را بگذار:

💻 ترمینال کامپیوتر شما
ssh root@SERVER_IP
✅ رمز سرور را می‌پرسد؛ بعد از زدنِ رمز، وارد سرور می‌شوی. از این‌جا به بعد در «ترمینالِ سرور» هستی.
2

پوشهٔ نصب‌کننده را روی سرور بیاور

💻 روی کامپیوترِ خودت (یک ترمینال جدید)

پوشهٔ ovpn-installer را از کامپیوترت به سرور کپی کن:

💻 ترمینال کامپیوتر شما
scp -r ovpn-installer root@SERVER_IP:/root/
اگر پوشه از قبل روی سرور هست این مرحله را رد کن و برو مرحلهٔ ۳.
3

نصب را اجرا کن

🖥️ در ترمینالِ سرور

وارد پوشه شو و نصب را اجرا کن. همین دو خط کافی است — بقیه‌چیز خودکار نصب می‌شود:

🖥️ ترمینال سرور (SSH)
cd /root/ovpn-installer
sudo bash install.sh
✅ نصب چند دقیقه طول می‌کشد (نصب OpenVPN و Node.js و ...). صبر کن تا پیام «نصب کامل شد» را ببینی.
می‌خواهی پورت یا پروتکل خاص باشد؟ به‌جای دستور بالا، این را بزن (مثال: پورت 443 و TCP و حجم پیش‌فرض ۳۰ گیگ):
🖥️ ترمینال سرور (SSH)
cd /root/ovpn-installer
sudo OVPN_VPN_PORT=443 OVPN_PROTOCOL=tcp OVPN_DEFAULT_LIMIT_GB=30 bash install.sh
پورت پنل با OVPN_PORT=4000 و DNS با OVPN_DNS1=1.1.1.1 قابل‌تغییر است.
4

رمز ادمین و آدرس پنل را بردار

🖥️ در ترمینالِ سرور

بعد از نصب، همهٔ اطلاعات دسترسی این‌جا ذخیره شده. این دستور را بزن تا ببینی‌شان:

🖥️ ترمینال سرور (SSH)
cat /root/ovpn-install-info.txt

چیزی شبیه این می‌بینی — این سه مورد را برای خودت جایی ذخیره کن:

📄 خروجی
Panel URL : http://SERVER_IP:4000/p-XXXXXXXX/     ← آدرس پنل
Admin Pass: aBcD1234...                            ← رمز ورود به پنل
API Key   : 4b30449c...                            ← کلید API
اگر «Admin Pass» خالی بود: یعنی سرور از قبل OpenVPN داشته. یک رمز جدید بساز (پایین همین صفحه: بخش «رمز ادمین را فراموش کرده‌ای؟»).
5

وارد پنل شو و کاربر بساز

💻 در مرورگرِ کامپیوترت

آدرسِ Panel URL از مرحلهٔ ۴ را در مرورگر باز کن، با Admin Pass وارد شو، و از داخل پنل کاربر بساز و فایل .ovpn را دانلود کن.

پنل باز نمی‌شود؟ مطمئن شو پورت‌های 4000/TCP (پنل) و 1194/UDP (OpenVPN) در فایروال سرور و پنل کلود باز باشند.
🎉 تمام! OpenVPN نصب و آمادهٔ استفاده است.

📎 (اختیاری) ساخت کاربر با API به‌جای پنل

اگر خواستی از سایت/ربات کاربر بسازی، با API Key (از مرحلهٔ ۴) این روت‌ها را صدا بزن:

کاردستور (در مرورگر یا با curl)
ساخت کاربرhttp://SERVER_IP:4000/create?apiKey=KEY&name=ali&dataLimitGB=30&expiresInDays=60
اطلاعات کاربر/info?apiKey=KEY&name=ali
افزایش حجم/تمدید/update?apiKey=KEY&name=ali&addDataGB=10&extendDays=30
غیرفعال/فعال/حذف/disable · /enable · /remove ?apiKey=KEY&name=ali
لیست کاربران/list?apiKey=KEY

نمونهٔ ساخت کاربر و ذخیرهٔ فایل کانفیگ:

🖥️ ترمینال سرور (SSH)
curl -s "http://SERVER_IP:4000/create?apiKey=API_KEY&name=ali&dataLimitGB=30" -o ali.ovpn

🔁 رمز ادمین را فراموش کرده‌ای (یا خالی بود)؟

🖥️ در ترمینالِ سرور

این دستور یک رمز جدید می‌سازد و جایگزین می‌کند (رمز قبلی باطل می‌شود):

🖥️ ترمینال سرور (SSH)
cd /home/ovpn
sudo OVPN_CONFIG_DIR=/etc/ovpn node -e 'const c=require("./lib/config.js");const p=require("crypto").randomBytes(12).toString("base64url");c.rotateAdminPassword(p);console.log("رمز جدید:",p)'
sudo systemctl restart ovpn.service
✅ رمزی که چاپ می‌شود، رمزِ جدیدِ ورود به پنل است.

🩺 مشکل داری؟

وضعیت سرویس‌ها را ببین:

🖥️ ترمینال سرور (SSH)
systemctl status ovpn.service            # پنل
systemctl status openvpn-server@server   # خودِ OpenVPN
journalctl -u ovpn.service -f            # لاگ زندهٔ پنل
  • QR کد کار نمی‌کند؟ طبیعی است — کانفیگ OpenVPN بزرگ‌تر از ظرفیت QR است؛ فقط از دانلود فایل .ovpn استفاده کن.
  • کاربر وصل نمی‌شود؟ پورت OpenVPN را در فایروال چک کن و مطمئن شو openvpn-server@server فعال است.
  • اطلاعات دسترسی همیشه این‌جاست: /root/ovpn-install-info.txt

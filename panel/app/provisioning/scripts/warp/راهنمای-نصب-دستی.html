🌐 نصب WireGuard با خروجی از وارپ یا پروکسی

وایرگاردی که IP خروجیِ کاربر را عوض می‌کند: یا از Cloudflare WARP، یا از یک پروکسیِ دلخواه. یکی از دو مسیر را انتخاب کن و از بالا به پایین دنبال کن.

❓ اول انتخاب کن: کدام را می‌خواهی؟

🟠 مسیر A — وارپ (WARP)

خودِ سرور Cloudflare WARP را نصب می‌کند و خروجی از وارپ می‌رود. نیازی به پروکسیِ بیرونی نداری.

4

Cloudflare WARP را نصب کن

🖥️ در ترمینالِ سرور

این سه بلوک را به‌ترتیب بزن (اول افزودن مخزن و نصب):

🖥️ ترمینال سرور (SSH) — نصب
curl -fsSL https://pkg.cloudflareclient.com/pubkey.gpg | sudo gpg --yes --dearmor -o /usr/share/keyrings/cloudflare-warp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/cloudflare-warp-archive-keyring.gpg] https://pkg.cloudflareclient.com/ $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/cloudflare-client.list
sudo apt-get update && sudo apt-get install -y cloudflare-warp

سپس ثبت و روشن‌کردنِ حالت proxy روی پورت 40000:

🖥️ ترمینال سرور (SSH) — راه‌اندازی
sudo warp-cli --accept-tos registration new
sudo warp-cli --accept-tos mode proxy
sudo warp-cli --accept-tos proxy port 40000
sudo warp-cli --accept-tos connect
نسخهٔ قدیمی warp-cli؟ اگر خطا داد، این‌ها را امتحان کن: register به‌جای registration new و set-mode proxy / set-proxy-port 40000.

تست کن که وارپ کار می‌کند (باید یک IP کلودفلر بدهد، نه IP سرور):

🖥️ ترمینال سرور (SSH) — تست
curl --socks5-hostname 127.0.0.1:40000 https://api.ipify.org
✅ اگر یک IP نمایش داد (مثلاً 104.x.x.x)، وارپ آماده است. برو مرحلهٔ ۵.
5

خروجیِ وایرگارد را به وارپ وصل کن

🖥️ در ترمینالِ سرور

این دو بلوک را بزن: اول فایل تنظیمات را بساز (پروکسی = همان وارپِ محلی)، بعد اعمال کن:

🖥️ ترمینال سرور (SSH) — ساخت فایل تنظیمات
sudo tee /etc/wvpn-proxy.env >/dev/null <<'EOF'
PROXY_IP=127.0.0.1
PROXY_PORT=40000
PROXY_TYPE=socks5
WG_NIC=wg0
REDSOCKS_LOCAL_PORT=12345
EOF
sudo chmod 600 /etc/wvpn-proxy.env
🖥️ ترمینال سرور (SSH) — اعمال
cd /root/wginstaller-proxy
sudo bash wvpn/proxy-egress.sh
🎉 تمام! حالا ترافیکِ کلاینت‌های وایرگارد از Cloudflare WARP خارج می‌شود. برای گرفتنِ اطلاعاتِ پنل و تست، برو بخش‌های پایین.

مشخصاتِ پروکسیِ خودت را وارد کن

🖥️ در ترمینالِ سرور

مقادیرِ PROXY_* را با مشخصاتِ پروکسیِ خودت جایگزین کن:

🖥️ ترمینال سرور (SSH) — ساخت فایل تنظیمات
sudo tee /etc/wvpn-proxy.env >/dev/null <<'EOF'
PROXY_IP=1.2.3.4
PROXY_PORT=8080
PROXY_TYPE=socks5
PROXY_USER=username
PROXY_PASS=password
WG_NIC=wg0
REDSOCKS_LOCAL_PORT=12345
EOF
sudo chmod 600 /etc/wvpn-proxy.env
نوع پروکسی: اگر SOCKS5 است socks5 بگذار، اگر HTTP است http-connect. اگر پروکسی یوزر/پس ندارد، دو خطِ PROXY_USER و PROXY_PASS را حذف کن.

🖥️ ترمینال سرور (SSH)
cd /root/wginstaller-proxy
sudo bash wvpn/proxy-egress.sh

🔑 اطلاعات پنل و کاربران

🖥️ در ترمینالِ سرور

برای دیدنِ آدرس پنل و کلید API:

🖥️ ترمینال سرور (SSH)
cat /etc/wvpn/wvpn.json          # apiKey و adminPath (آدرس پنل)
cat /etc/wireguard/params        # پورت وایرگارد و کلید عمومی سرور

آدرس پنل: http://SERVER_IP:4000/<adminPath>/

ساخت کاربر با API (کلاینت با name شناخته می‌شود؛ خروجی = کانفیگِ آمادهٔ وایرگارد):

🖥️ ترمینال سرور (SSH)
curl -s "http://SERVER_IP:4000/create?apiKey=API_KEY&name=ali" -o ali.conf
کارروت
ساخت/create?apiKey=KEY&name=ali
اطلاعات / لیست/info?...&name=ali · /list?apiKey=KEY
حذف/remove?apiKey=KEY&name=ali

✅ تست خروجی

از داخلِ یک کلاینتِ وایرگاردِ متصل، این را بزن — باید IP پروکسی/وارپ را نشان دهد، نه IP سرور:

📱 روی دستگاهِ کلاینتِ متصل
curl https://api.ipify.org

🔁 پروکسی خراب شد؟ عوضش کن

🖥️ در ترمینالِ سرور

فایل تنظیمات را ویرایش کن، دوباره اعمال کن، و redsocks را ری‌استارت بزن (پروکسیِ قبلی خودکار جایگزین می‌شود):

🖥️ ترمینال سرور (SSH)
sudo nano /etc/wvpn-proxy.env          # مقادیر جدید را بگذار و ذخیره کن
cd /root/wginstaller-proxy
sudo bash wvpn/proxy-egress.sh
sudo systemctl restart wvpn-redsocks

🩺 مشکل داری؟

🖥️ ترمینال سرور (SSH)
systemctl status wvpn-redsocks     # وضعیت خروجیِ پروکسی
warp-cli --accept-tos status       # وضعیت وارپ (فقط مسیر A)
wg show                            # وضعیت وایرگارد
  • خروجی هنوز IP سرور را نشان می‌دهد؟ مطمئن شو wvpn-redsocks فعال است و پروکسی/وارپ واقعاً کار می‌کند.
  • بعد از هر تغییرِ فایلِ /etc/wvpn-proxy.env، حتماً sudo systemctl restart wvpn-redsocks بزن.
  • پورتِ وایرگارد (UDP) و پورت پنل (4000/TCP) باید در فایروال باز باشند.
